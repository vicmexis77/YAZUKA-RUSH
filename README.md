# 🗡️ Katana vs Zombie Horde

Un juego de acción, supervivencia y desplazamiento lateral 2D desarrollado en Python utilizando la librería **Pygame**. Enfrenta hordas de zombies, gestiona tu armamento y avanza a través de diferentes niveles.

---

## 📋 Requisitos Previos

Asegúrate de contar con lo siguiente antes de ejecutar el proyecto:

* **Python 3.8** o superior instalado en tu sistema.
* **Pygame** para la renderización gráfica y gestión de eventos/audio.

Cómo Ejecutar el Juego
Una vez instaladas las dependencias y verificados los archivos de recursos, inicia el script principal ejecutando:

Bash
python main.py
🎮 Controles y Contenido
Menú Principal
Flecha Arriba / Flecha Abajo: Navegar por las opciones (Jugar, Opciones, Salir).

Enter: Confirmar selección.

Controles en Juego
A / D: Moverse hacia la izquierda o derecha.

E: Desenfundar / Enfundar la katana.

Clic Izquierdo: Disparar en la dirección del puntero (requiere arma desenfundada).

Espacio: Interactuar con la puerta de salida para avanzar de nivel.

🕹️ Mecánicas Clave
Sistema de Estados y Armamento: Al desenfundar el arma (E), el puntero del ratón cambia a una mira personalizada y habilita el sistema de disparo.
